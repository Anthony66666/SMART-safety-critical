# 安全关键场景生成：选项一实施计划

## Context

**要解决的问题.** 安全关键场景生成领域存在一个无法证伪的声明：每篇论文都说"我们的场景既真实又危险"，但真实性一律用代理指标衡量（AdvSim 用运动学约束，KING 用可微代理 loss，STRIVE 用 VAE 的 ELBO 下界，CTG++ 用扩散先验的隐式正则）。没有公共标尺，"你生成的场景根本不会发生"这条批评谁都反驳不了。

**为什么这个仓库能解.** SMART 是自回归离散 token 模型，序列对数似然**精确可算**，且 2048 个 token 每个自带显式几何（`token_all['veh']` 形状 `(2048, 6, 4, 2)`，已实测）。这让两件事成为可能：(1) 真实性有确切定义，对抗生成变成 KL 约束控制问题，最优解闭式 `π* ∝ p·exp(J/β)`，只有一个旋钮 β；(2) 重要性权重 `w = p/q` 可精确计算，从而做**无偏**的稀有事件风险估计——这是 ELBO 模型和扩散模型做不到的。

**目标产出.** 两段式 program：
- **Track A（稳线）**：似然约束下的对抗生成 + Pareto 前沿评测协议 → 一篇 CVPR/ICCV 主会论文
- **Track B（高线）**：把生成变成带置信区间的失效概率估计 + 失效模式分解 → 更高天花板的第二篇

两条线共享同一个数学对象：Track A 的 β-倾斜分布 `π*` 正是 Track B 的重要性采样 proposal。第二篇回头给第一篇更深的解释。

## 实测结论（2026-08-26）

以下都是本地实测得到的，不是设计假设。它们已经改变了 Track A 的度量定义。

### 真实性度量：已定型为下尾，不是均值

**均值 log p 对上下文错误失明，而且是构造性的失明。** n=60，WOMD validation，自评，全支撑：

| 统计量 | logged vs generated | generated vs permuted |
|---|---|---|
| mean | t=+21.3 | **t=+0.65 失明** |
| median | t=+15.1 | **t=-3.56 反向** |
| p25 | t=+19.9 | t=+1.72 |
| p10 | t=+22.5 | **t=+5.38** |
| min | t=+12.7 | **t=+10.3** |

机制：错误场景 = 多数 agent 正常 + 少数灾难；模型样本 = 整体平庸但无灾难。均值把正的尾部效应和负的中位数效应相消，恰好抵在零点。

**但 min 只适用于整体被打乱的情形。** 单 agent 扰动下 min 同样失明（t=-1.00）：被扰动 agent 只掉到 -2.6，而场景基线最小值本就在 -5.6，它永远成不了场景里最差的那个。

因此度量按对比类型分开：
- **整体比较**（真实 vs 生成 vs 打乱）→ 下尾 `min` / `p10`
- **对抗场景**（少数指定 agent）→ **该 agent 的 `Δlog p` 相对自身基线**，不是任何场景级聚合

### 前沿原点：校准温度 T*

每个场景都存在一个温度，使生成场景与真实场景等似然。中位数 **T\* = 0.841**，IQR **[0.802, 0.893]**，60/60 场景都找得到。

分布窄到可视为**模型常数而非场景性质**。两个用处：
- 给 Pareto 前沿一个有原则的原点，不必任意指定"基准配置"
- 同时说明：SMART 在默认 T=1 采出的场景，**按它自己的度量就比真实交通更不可能**

### 响应性：门已通过，但外推要谨慎

| 探针 | 逐场景单调 | 效应 |
|---|---|---|
| 单 agent 横移 0→6m | 4/60 | -0.645 nats, t=-8.62, 57/60 下降 |
| 温度 0.75→1.25 | **60/60** | -4.455 nats, t=-62.8, 60/60 下降 |

温度是**全局**扰动（所有 agent、所有步），所以响应极干净；单 agent 横移是**局部**扰动，所以逐场景噪声大。

⚠️ **β 倾斜介于两者之间**——形式上是全局重加权，但效应会集中在 ego 附近的少数 agent。**不能用温度的干净度外推 β 前沿一定好看。**

### M4 危险倾斜前沿：门已过（2026-08-26）

`q ∝ p·exp(J/β)` 端到端跑通。n=60，自评，全支撑，均值前沿：

| β | 危险度 (m) | 对抗者 log p/步 | 碰撞 |
|---|---|---|---|
| off | -4.015 | -3.728 | 5/60 |
| 1.0 | -2.690 | -4.135 | 15/60 |
| 0.5 | -2.262 | -4.208 | 18/60 |
| 0.25 | -0.745 | -4.297 | 32/60 |
| 0.10 | -0.344 | -4.493 | 37/60 |

**均值前沿 7 个点两轴全单调。** 危险度 -4.0m→接触，realism 仅降 ~0.77 nats；碰撞率 8%→62%，代价 <1 nat。

**结构性优势有数字了**：温度要牺牲 4+ nats 才能移动同等 realism（毁掉整个场景），倾斜只重加权单个 agent → 便宜得多。这是对比扩散引导的核心卖点。

**逐场景噪声**（如风险 6 预警）：危险度完全单调 30/60、realism 9/60，对比温度 60/60。**前沿每点必须对多场景平均**。仍循环，需 M1 裁判才算真实性主张。

### 已排除的度量（勿重试，证据已在代码里）

- **BPD**：`-mean/ln2`，纯换底。排序、t 统计量、分辨力完全不变（logged 3.44 / generated 5.44 / permuted 5.52）。保留为论文报告单位，不是更锋利的工具。
- **典型性** `ε=|-log p/D - ref|`：`ref=H(model)` 时**真实交通排最差**（模型过弥散，H=3.77 vs CE=2.39）；`ref=CE(data)` 时排序正确但分不开生成与打乱（t=-1.61）。两种参考系都不可用。

### 两个必须遵守的工程约束

- **确定性**：`sample_pt_pred` 的地图点掩码是训练增强，**必须设种子**。两次未设种子的加载会给模型不同的地图上下文——这曾造成 9e-2 的似然偏差，且被误判为浮点非确定性。修正后 teacher-forced 重算精确复现（差值 0）。
- **设备**：诊断脚本此前一直跑在 CPU 上。改 GPU 后单次 rollout 从 ~2.2s 降到 ~0.27s（约 8 倍），大规模实验预算据此下调。

## 代码现状：三个前置事实（**均已处理**）

均为实测确认。三条都已落地，保留原文以说明为何这样改。

**1. `pred_prob` 已经是精确的 p。** ✅ 已落地（M0）
[agent_decoder.py:435-458](smart/modules/agent_decoder.py:435) 先对全 2048 做 `softmax`，再 `topk(k=beam_size)`，`pred_prob` 存的是**全量 softmax 下**的概率、未重归一化。所以 `log p` 直接可得。缺的只是采样分布 q：`multinomial` 在 top-5 上采样，`q = p / Z`，其中 `Z = topk_prob.sum(-1)` **当前未记录**。补一行即可。

**2. `beam_size = 5` 硬编码**（[agent_decoder.py:107](smart/modules/agent_decoder.py:107)）。✅ 已改为可配（M0）
top-5 截断意味着 q 的支撑集只有 5 个 token，支撑外的场景概率为 0、永远采不到。Track B 的无偏估计**要求全支撑**，必须把 `beam_size` 变成可配置项，风险估计路径下设为 2048。

**3. 没有 ego planner。** ✅ 已新建（M3）
[agent_decoder.py:379](smart/modules/agent_decoder.py:379) 的 `av_mask` 定义了但**从未使用**——SMART 把 AV 当普通 agent 一起 rollout。整个项目要攻击的对象目前不存在，必须新建。

## Track A：似然约束的对抗生成 + Pareto 前沿

### A.1 倾斜采样器

**新建** `smart/safety/tilting.py`

在 token 循环内实现 `π* ∝ p·exp(J/β)`：每步对全 2048 个候选 token 展开几何、精确算 `J`、按 `p·exp(J/β)` 重加权后采样。**无梯度、无可微代理**。

三个求解器变体（论文的 method 章节）：
1. **training-free 逐 token 引导**（主力，最能体现离散结构优势）
2. 序列级重采样（SIR）
3. 蒸馏成 amortized 策略（可选，时间不够可砍）

### A.2 Pareto 前沿评测协议

扫 β，每个 β 得到一个（裁判似然, 攻击成功率）坐标点，连成曲线。所有 baseline 作为曲线下方的散点。**这是论文的 Fig. 1。**

**真实性轴的确切定义**（见「实测结论」）：用**对抗 agent 的 `Δlog p` 相对自身基线**，不是场景级均值也不是场景级 min——单 agent 扰动下场景级聚合已实测失明。前沿原点取校准温度 **T\*≈0.841**（生成与真实等似然处）。

⚠️ 每个 β 点**必须对多场景平均**：单场景读数是噪声的（单 agent 探针逐场景单调仅 4/60）。

**新建** `scripts/gen_scenarios.py`（本地小规模 → 服务器全量）

### A.3 诊断实验（决定这篇文章的量级）

把已发表方法的场景放到裁判下打分，展示它们的似然掉到什么程度。**这是开篇第一击**，把"大家默认存在但从未被测量"的问题变成有数字的问题。

**现状 🔶**：打分链路已就绪（`scripts/run_diagnostic.py` + teacher-forced 的 `forced_tokens`），度量也已定型。**卡在两件事上**：需要 baseline 方法的场景（M5，可外包），以及独立裁判（M1，已推迟）。现有数字全部是循环的，只能证明管道通、不能当证据。

如果最终差距不明显，及时把主线换成多智能体协同对抗——那条线只需要类别级分离，而类别级分离**已经实测拿到**。

### A.4 加分组件（便宜，图好看）

- **token 空间最小反事实**：改动最少多少个 token 能让 planner 失效。离散 token 让编辑距离成为天然可解释度量，连续方法无法这样表述。
- **多智能体协同对抗**：SMART 的 a2a attention 天然建模联合分布，可生成多车配合的场景，而真实性约束会自动让配角保持正常行为。AdvSim/STRIVE/CAT 基本都是单对抗体，这是空白。

### A.5 Baseline（适合分工外包）

AdvSim、STRIVE、CAT、KING、CTG++ 的复现或迁移。机械但耗时，是最适合交给合作者的部分。

## Track B：稀有事件风险估计

### B.1 估计量

**新建** `smart/safety/estimators.py`

朴素重要性采样在序列空间（16 步 × N agent）**必然失败**——权重方差随维度指数爆炸，ESS 塌到 1。这不是"可能有点麻烦"。

因此直接上**序贯蒙特卡洛 / 自适应多层分裂（AMS、subset simulation）**：粒子边推进边重采样，ESS 低于阈值就分裂。离散 token 树天然适合。

用交叉熵方法自适应学 β。

### B.2 半合成验证环境（**不做这个，没人会信任何数字**）

**新建** `smart/safety/validation/`

构造一个规模小到可以**暴力枚举出真值 P(fail)** 的场景族（少量 agent、短时域、受限 token 子集），验证估计量确实无偏、CI 覆盖率正确。

这是 Track B 唯一的硬性前置门槛。**验收**：估计值落在暴力真值的 CI 内，覆盖率接近名义水平。

### B.3 失效模式分解

**新建** `smart/safety/modes.py`

`P(fail) = Σ_m P(fail ∧ mode m)` → "总风险 2.3×10⁻⁵，其中 61% 来自『无保护左转 + 遮挡』"。用 token 序列本身做失效场景的表示来聚类。这是给 AV 安全工程师的杀手级表格。

### B.4 模型敏感性（诚实性要求）

跨多个独立训练的模型报告估计值。**如果估计值在不同模型间差 100 倍，这个数字就没有意义，必须如实报告**，而不是挑一个好看的报。

## 已知风险

**1. 循环论证（Track A 的头号风险）.** 用 SMART 打分 SMART。缓解：0.3 的独立裁判 + 小规模人类评测（20-30 场景，问"这像真实路况吗"）并与裁判似然算相关性。注意 A.3 的诊断实验说"别人的场景不真实"同样需要裁判才站得住——这两件事是同一个问题，一次解决。

**2. 权重退化（Track B 的生死线）.** 朴素 IS 必然失败。缓解：B.1 直接上 SMC/AMS，且 B.2 早做原型验证。

**3. "校准的是模型，不是现实".** 估计的是 SMART 定义的分布下的 P(fail)。这是风险 1 换了身衣服，但因为报的是具体数字，攻击面更大。缓解：B.4 敏感性 + B.2 半合成验证 + 留出似然论证拟合质量。

**4. 离散词表的表达力上限.** 2048 个 token 覆盖不了任意运动，攻击强度可能弱于连续优化。应对：不回避，直接报同等真实性下的对比。预期结论是——同等真实性约束下你赢，不限真实性时你输。**这个结论本身就是 Pareto 图要讲的话。**

**5. 与 CAT (NeurIPS 2023) / STRIVE (CVPR 2022) 的区分度.** CAT 已在做"用预测模型似然加权挑对抗模式"，精神接近 `p·exp(J/β)`。必须在 related work 正面挑明：CAT 是单对抗体、启发式重加权、无真实性度量、无权衡曲线。主动区分比回避更显专业。

**6. β 响应未经验证，不能从温度外推.** 温度扫描逐场景单调 60/60，但温度是全局扰动；单 agent 扰动只有 4/60。β 倾斜介于两者之间，前沿是否平滑**仍是开放问题**。缓解：M4 一开始就先扫一个小 β 网格看形状，再投入完整实验。

**7. 磁盘.** 仅剩 109G。rollout 产物、裁判 checkpoint 需要控制体积或及时清理。
